## ✅ Requisitos

Antes de instalar o ejecutar la barra, asegurate de tener:

- **Sistema operativo:** Windows **64 bits** (no compatible con Windows de 32 bits).
- **VLC Media Player instalado** — es **obligatorio**. La barra usa VLC para el reproductor de música integrado y para la función de TV en vivo (IPTV). Sin VLC instalado, esas dos funciones no van a arrancar.
  - Descargar VLC (gratuito): <https://www.videolan.org/vlc/>
  - Instalá la versión de VLC que coincida con tu sistema (64 bits).

## 🚀 Inicio

Al hacer clic en el icono de la aplicación, se inicia la barra. Puede aparecer abierta o cerrada según cómo haya quedado la última vez.

**Atajo de teclado:** con `Tab` + `Z` se oculta o se muestra la barra en cualquier momento.

## 🖱️ Menú de opciones

Desde el menú de la barra (los tres puntos) accedés a:

![Menú de opciones]
<img width="705" height="78" alt="menuT" src="https://github.com/user-attachments/assets/9e482148-4606-4989-9460-b5627e1bb696" />


<img width="252" height="302" alt="menu2" src="https://github.com/user-attachments/assets/439b6b0a-4918-4bb8-9dd8-7ed414e86de6" />

- **Imagen del personaje…**: elegís la imagen del asistente. Puede ser un GIF animado, al gusto del usuario.
- **Iniciar con Windows**: la barra queda activa siempre; al encender el equipo tarda un poco en aparecer.
- **Reproductor de música**: reproductor integrado y personalizado dentro de la barra (requiere VLC, ver [Requisitos](#-requisitos)).
- **TV**: reproductor de canales abiertos vía IPTV. Usa la lista pública `https://iptv-org.github.io/iptv/index.m3u` (requiere VLC, ver [Requisitos](#-requisitos)).
- **Ocultar accesos rápidos**: podés ocultar o volver a mostrar la barra, con botón o directamente con `Tab + Z`.
- **Personalizar barra**: colores, nombres, tarjetas y caras (ver más abajo).
- **Barra izquierda o derecha**: elegís a qué lado de la pantalla se ancla.
- **Salir**: cierra todo.

## 📌 Fijar la barra

El botón de fijar (pin) hace que la barra ocupe su propio espacio en la pantalla y no se deje ocultar. Si lo desactivás, la barra vuelve a poder ocultarse normalmente.

## 🙂 Caras (agrupar por proyecto o cliente)

Cada "cara" es una agrupación independiente de accesos: podrás
 tener una cara para un cliente, otra para un proyecto, otra para tus libros, etc. Hay hasta **50 caras** disponibles, y cada punto de la parte inferior representa una.

![Puntos de caras]
<img width="689" height="347" alt="caras1" src="https://github.com/user-attachments/assets/6b3eda05-3781-4434-aeac-70104181328a" />

- **Cambiar de cara**: hacé clic sobre el punto correspondiente.
- **Renombrar una cara**: doble clic sobre el nombre para ponerle el que quieras (por ejemplo, el nombre de un cliente).

![Renombrar cara]
<img width="306" height="237" alt="caras2" src="https://github.com/user-attachments/assets/86837fed-0729-4eed-94a6-3ba3a6c39aa7" />


- **Biblioteca de caras**: te muestra todas las caras activas y cuántas llevás usadas del total de 50, útil cuando ya tenés varias configuradas.

![Biblioteca de caras](assets/10-biblioteca-caras.png)
<img width="367" height="599" alt="caras3" src="https://github.com/user-attachments/assets/5d393257-ee89-4fe1-befa-32866ed0a866" />

En la parte central de cada cara podés agregar todos los `.exe` que quieras (tuyos o de Windows: Excel, Paint, etc.), además de archivos, carpetas y URLs. Es ideal para agrupar todo lo relacionado a un proyecto o cliente en un solo lugar.

**Botón para agregar elementos:** te deja elegir entre Aplicación (`.exe`), Carpeta, Archivo o Página web (URL).
